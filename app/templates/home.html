Running it

# from the repository root
pip install -r week_2/module2/requirements.txt
python app/app.py                            # this application, all assignments
python app/app.py --port 8000 --debug

The application holds no computation of its own: each assignment's pages import that assignment's own modules, so the web pages and the command-line tools run the same code and cannot disagree.
