Four-view structure from motion

Tomasi–Kanade factorization (FPCV-4-4) of a flat object seen from four viewpoints: centroid-subtracted observation matrix W, rank constraint by SVD (rank 2 for a plane), and the matrix Q from the orthonormality of each camera's i, j by Newton's method. Lens distortion and intrinsics are removed with the Module 2 calibration.

Your own four photos

Same phone, 1× lens, portrait, full resolution, as calibrated in Module 2. JPEG or PNG. Take all four from about the same distance (the orthographic model assumes one magnification), well away from the object, with different viewing directions.

Click the same object corners in the same order in every photo, walking around the outline. Then give one real distance you measured with a ruler.
